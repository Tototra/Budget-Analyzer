Installation
Avant de lancer Budget Analyzer

L'application utilise un modele d'IA qui tourne sur ta machine pour classer les transactions ambigues. Il faut installer Ollama (gratuit, 2 minutes).

1

Installer Ollama

Telecharge et installe Ollama depuis le site officiel :

ollama.ai/download
macOS — Telecharge le .dmg, glisse dans Applications, lance Ollama. Une icone apparait dans la barre de menu.
Windows — Telecharge le .exe, installe et lance. Ollama tourne en arriere-plan dans la barre des taches.
Linux — Une seule commande : curl -fsSL https://ollama.ai/install.sh | sh
2

Telecharger le modele

Ouvre un terminal et lance cette commande (2 Go a telecharger, une seule fois) :

ollama pull llama3.2:3b

C'est un modele leger qui tourne sur n'importe quel ordinateur recent. Pas besoin de carte graphique.

3

Lancer Budget Analyzer

Assure-toi qu'Ollama tourne (l'icone est visible dans la barre de menu/taches), puis lance Budget Analyzer. L'application detecte automatiquement Ollama et t'indique si quelque chose manque.
