# Budget Analyzer — CLAUDE.md

## Design rules

- **No emojis anywhere** — not in the UI, not in headings, not in buttons, not in badges. Use icons (SVG or CSS shapes) when a visual marker is needed.
- The app should look like a real fintech product (Revolut, N26, Mercury, Linear). Clean, minimal, premium.
- Use Inter for body text, Space Grotesk for display/headings.
- Animations should be smooth and purposeful — entrance transitions, hover effects, micro-interactions.
- French language throughout.
- The landing page is a standalone site deployed online, NOT a Claude artifact.
- The app (Flask + HTML/JS frontend) runs locally at localhost:8080.
